📈 统计学基础
1. 简述描述性统计与推断统计的区别。
描述性统计用于概括和描述数据的基本特征（均值、中位数、标准差、分布形态等）；推断统计通过样本数据推断总体特征（置信区间、假设检验、回归分析等）。
2. 什么是正态分布？为什么很多统计方法假设数据正态？
正态分布是钟形对称分布，均数=中位数=众数。很多统计方法（t检验、ANOVA）基于正态假设以保证估计有效性；大样本下中心极限定理使样本均值趋近正态，因此正态性假设常可放宽。
3. 解释P值、置信区间和显著性水平α的关系。
P值是在原假设成立下观察到当前结果或更极端结果的概率；α是预先设定的显著性水平（通常0.05）；若P<α则拒绝原假设。置信区间是以一定置信水平（1-α）包含总体参数的区间，若区间不包含零值（或假设值），则等价于拒绝原假设。
4. 第一类错误和第二类错误分别是什么？如何降低？
第一类错误（假阳性）：原假设正确但拒绝；降低方法：减小α。第二类错误（假阴性）：原假设错误但未拒绝；降低方法：增大样本量、提升检验效能（power）。
5. 什么是中心极限定理？对数据分析有何意义？
样本均值的分布趋近正态分布，无论原始分布形态如何（样本量足够大时）。意义：为统计推断（如计算置信区间、假设检验）提供理论基础，使t检验、Z检验等可以使用。
6. 方差与标准差的区别与联系。
方差是各数据与均值差平方的平均，单位是原数据单位的平方；标准差是方差的平方根，单位与原数据一致，更常用于解释波动性。
🗄️ SQL 查询
1. 写出统计每个部门的平均薪资，并按平均薪资降序排列的SQL。
SELECT department, AVG(salary) as avg_salary FROM employees GROUP BY department ORDER BY avg_salary DESC;
2. 解释INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN的区别。
INNER JOIN 只返回匹配的行；LEFT JOIN 返回左表全部+右表匹配行，不匹配则NULL；RIGHT JOIN相反；FULL OUTER JOIN 返回左右表所有行，不匹配部分补NULL（MySQL不直接支持但可用UNION模拟）。
3. 如何查找某字段重复的记录？
SELECT column, COUNT(*) FROM table GROUP BY column HAVING COUNT(*) > 1;
4. 窗口函数ROW_NUMBER()、RANK()、DENSE_RANK()的区别。
ROW_NUMBER()为每个分组内行分配唯一连续序号；RANK()并列时跳过后续名次（如1,2,2,4）；DENSE_RANK()并列时不跳号（1,2,2,3）。
5. 一条SQL查询的执行顺序（写出关键字顺序）。
FROM → JOIN → ON → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT。理解此顺序有助于优化和调试慢查询。
🐍 Python 数据分析（Pandas & Numpy）
1. Pandas如何删除缺失值？
df.dropna() 删除含有NaN的行；df.dropna(axis=1)删除列；可传入thresh参数保留至少非NaN数量；也可用df.fillna()填充特定值。
2. 简述apply()和map()的区别。
map()用于Series元素转换，不能传递额外参数；apply()可用于Series或DataFrame，可以逐行/逐列操作并传递复杂函数或lambda，更灵活。
3. 如何高效合并两个DataFrame？
使用pd.merge()类似SQL join；pd.concat()按行或列拼接；也可使用join()方法基于索引合并。根据业务选择合适方法。
4. groupby之后如何保留原DataFrame的其他列？
常用transform()将聚合结果广播回原维度；或使用agg()配合分组键+merge；另可使用groupby + apply返回带标签的结果。
5. Numpy中axis=0和axis=1的含义？
axis=0表示沿行方向操作（跨行），常用于按列计算（如np.mean(axis=0)返回各列均值）；axis=1表示跨列操作（逐行）。
📊 数据可视化
1. 如何选择合适的图表类型？
比较数值：条形图、柱状图；趋势与时间序列：折线图；占比：饼图（类别少）、环形图；分布：直方图、箱线图；关系：散点图、气泡图；多变量相关性：热力图。
2. 解释箱线图的组成部分及异常值判定。
箱线图包括中位数、上四分位数（Q3）、下四分位数（Q1）、上边缘（Q3+1.5IQR）、下边缘（Q1-1.5IQR）。超出上下边缘的点视为异常值。
3. 条形图和直方图的核心区别？
条形图用于分类变量，条之间有空隙；直方图用于连续变量分组，条之间无间隔，且宽表示组距，面积表示频率。
4. 数据可视化的“数据墨水比”是谁提出的，含义是什么？
由Edward Tufte提出，指用于展示数据的墨水占总墨水的比例；高数据墨水比意味着去除冗余装饰元素，使图表更清晰高效。
📌 业务分析 & 指标体系
1. 什么是北极星指标？举一个产品的例子。
北极星指标是能直接反映产品为用户创造价值的核心指标，指引团队向同一方向努力。例如Spotify的“总听歌时长”，Airbnb的“过夜预订数”。
2. DAU、MAU、留存率的定义。
DAU: 日活跃用户数；MAU: 月活跃用户数；留存率：新增用户在指定时间后仍使用产品的比例（次日、7日、30日留存）。
3. 如何分析某功能上线后的效果？
采用A/B测试（控制组与实验组）；同时分析核心指标（点击率、转化率、留存）；排除季节因素、用户组成差异；还可进行同期群分析、差异中的差异（DID）等。
4. 简述OSM模型和UJM模型。
OSM（目标-策略-度量）：明确业务目标，制定策略，以及对应的度量指标。UJM（用户旅程地图）用户从认知到转化的完整路径，旨在发现各阶段的痛点和机会点。
🧪 A/B测试与实验设计
1. A/B测试的步骤有哪些？
①确定目标与假设；②确定实验单元（用户/设备）及样本量；③随机分流；④实施实验并收集数据；⑤检验统计显著性；⑥分析结果并决策（全量/回滚/继续迭代）。
2. 样本量如何估算？
取决于显著水平α、统计功效1-β、最小可检测效应MDE、基线转化率及数据方差。可使用在线计算器或公式: n=2*(Zα/2+Zβ)² * p*(1-p) / (Δ²) (比例类指标)。
3. 什么是辛普森悖论？如何避免？
总体趋势与分层趋势相反的现象，常因忽略混杂变量导致。避免方法：实验前合理分层随机化，分析时按关键变量（如地域、用户类型）进行细分后再综合。
4. 如何检验AB实验的分流是否均匀？
用卡方检验（ χ² ）检验实验组与对照组在样本量、用户属性（性别、新老用户等）分布上是否有显著差异；若P>0.05可认为分流随机均匀。
🤖 机器学习与建模基础
1. 过拟合与欠拟合的表现及解决方法。
过拟合：训练集表现优但测试集差（高方差） → 增大数据量、正则化、减少特征、早停。欠拟合：训练集表现差（高偏差） → 增加特征、提高模型复杂、减少正则化。
2. 如何评估分类模型？
混淆矩阵、准确率、精确率、召回率、F1-score、ROC曲线与AUC、PR曲线。对不平衡分类常关注AUC或PR曲线。
3. 特征选择的方法有哪些？
过滤法（方差阈值、相关系数、卡方检验）、包装法（递归特征消除RFE）、嵌入法（L1正则化、树模型特征重要性）。
4. 处理类别不平衡数据的常用方法。
重采样（过采样SMOTE、欠采样）；调整样本权重；使用恰当评估指标（AUC、F1）；集成方法（EasyEnsemble、BalancedBagging）；异常检测视角。
5. 逻辑回归是线性模型还是非线性模型？为什么可做分类？
逻辑回归是广义线性模型，决策边界是线性的；通过sigmoid函数将线性输出映射到概率区间，并以最大似然估计求解参数，用于二分类或多分类。
💼 开放业务场景题
1. 订单量下降了5%，请分析可能原因并给出排查思路。
首先确认数据准确（无计算错误）；然后外部因素（节假日、竞品活动、舆情、支付故障）；内部因素（前端改版、推荐策略、促销结束、渠道投放变化）；按维度拆分（地区、用户类型、时段），通过漏斗分析定位问题环节。
2. 如何衡量一个新推荐算法上线对GMV的影响？
采用A/B测试，分流用户；实验组新算法对照组旧算法；计算GMV per user的提升，同时观察点击率、转化率、客单价、长期留存等辅助指标；做显著性检验及分层分析。
3. 如果AB实验结果显示两组没有显著差异，如何决策？
①检查实验是否天数足够、样本量达到预期；②是否有新奇效应或网络效应干扰；③查看置信区间是否包含有意义的效应量；④结合成本收益决定是否全量；⑤尝试对特定人群（高活跃用户）进行亚组分析。
🛠️ 代码与工具实操
1. Python中如何用一行代码计算列表的平方和？
sum([x**2 for x in lst])。面试常考察列表推导式与sum组合。
2. Pandas中读取超大CSV文件如何优化？
使用chunksize参数分块读；指定dtypes降低内存；读取需要的列；使用nrows参数采样测试；转化为parquet等列式存储格式。
3. SQL中什么情况下索引会失效？
对索引列进行函数操作（如 YEAR(date)）；隐式类型转换；使用LIKE '%pattern%'；复合索引未使用最左前缀；全表扫描比索引更快（小表）。
4. 解释透视表pivot_table与melt的用途。
pivot_table将长格式数据转为宽格式（行转列），常用于汇总统计；melt将宽格式转为长格式（列转行），用于数据重构适应某些可视化库。
