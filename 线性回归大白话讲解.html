📈 大白话线性回归

拒绝数学焦虑 · 3分钟彻底看懂

🤔 线性回归在干啥？一句话：画一条最佳直线

给你一堆点（比如房子的面积和价格），线回归要做的就是找到一条直线，让这些点尽量靠近这条线。这样以后你给一个面积，就能用这条线猜出大概价格。

💡 生活类比：就像你小时候学“身高-体重”规律，虽然每个人不一样，但你大概能画条线，身高越高一般越重。线性回归就是让机器学会画这条线。
# 伪代码感受一下 # 输入：房子面积 x，真实价格 y # 模型：价格 = w * 面积 + b # 训练：找最好的 w 和 b，让预测尽量准

📐 数学公式？其实就是 y = kx + b

没错，就是初中数学！y = w·x + b（w 是斜率，b 是截距）。

  • x：特征（面积、年份…）
  • y：要预测的值（价格）
  • w：权重（每增加一个面积，价格涨多少）
  • b：偏置（房子基础价）

多特征呢？ 就是 y = w₁x₁ + w₂x₂ + … + b，还是一根“直线”在高维空间的推广。

✅ 记住：线性回归假设输入和输出是线性关系（也就是成比例变化）。

🎯 怎么“学”出线？—— 损失函数 & 梯度下降

损失函数（均方误差 MSE）：就是把预测值和真实值的差距平方再平均。差距越小，线越好。

损失 = (预测₁ - 真实₁)² + (预测₂ - 真实₂)² + … 再取平均

梯度下降：就像一个蒙眼下山的人，每次试探哪个方向使得损失变小，就迈一小步。反复迭代，直到找到最低点（最优线）。

🔁 面试官常问：为什么用平方而不是绝对值？ → 平方放大大误差，对异常值更敏感，且可导，方便数学优化。

面积、卧室数 → 预估总价

🎤 面试必问考点（背下来就能过）

Q1：线性回归的假设是什么？
→ ① 线性关系；② 误差独立同分布（正态分布）；③ 无多重共线性（特征之间不高度相关）。
Q2：怎么评估回归模型好坏？
→ R² (决定系数)：模型解释了数据多少变异性，越接近1越好。
→ MSE / MAE / RMSE：预测误差绝对值/平方根。
Q3：线性回归 vs 逻辑回归的区别？
→ 线性回归预测连续值，逻辑回归预测概率（分类）。逻辑回归在线性回归输出套上 sigmoid 函数。
Q4：过拟合怎么办？
→ 正则化：岭回归（L2） + Lasso（L1）；或增加数据量、减少特征。
Q5：梯度下降调参？
→ 学习率太大不收敛，太小太慢；需要做特征缩放（归一化）加速收敛。

🧠 面试手撕线性回归？不慌，写个类

import numpy as np class LinearRegressionGD: def __init__(self, lr=0.01, epochs=1000): self.lr = lr self.epochs = epochs self.w = None self.b = None def fit(self, X, y): n_samples, n_features = X.shape self.w = np.zeros(n_features) self.b = 0 for _ in range(self.epochs): y_pred = X @ self.w + self.b dw = (1/n_samples) * X.T @ (y_pred - y) db = (1/n_samples) * np.sum(y_pred - y) self.w -= self.lr * dw self.b -= self.lr * db def predict(self, X): return X @ self.w + self.b

面试官问你原理：就是不断调整 w 和 b，让损失变小。上面代码展示了最核心的梯度下降更新。

⚠️ 新手常踩的坑

  • 不标准化特征：范围大的特征会主导梯度更新 → 做 StandardScaler。
  • 忽略多重共线性：特征高度相关会使模型不稳定 → 用相关性矩阵检查或使用岭回归。
  • 数据泄露：把未来信息放进训练 → 划分时间序列时注意时序。
  • 认为线性回归永远好使：非线性关系时要用多项式回归或树模型。
🧪 小实验：用 sklearn 的 make_regression 生成数据，拟合后画图看残差，直观感受模型好坏。

✅ 一句话总结

线性回归 = 找一条直线让所有点离它最近 → 用损失函数衡量 → 梯度下降优化 → 预测新数据。

它是机器学习的“hello world”，简单但深刻。面试时讲出假设、评估、优缺点，就能过关。
